# ArtGalleryManager

Тестове завдання Techstack (Trainee, Full-Stack JS): система управління художньою галереєю.

**Стек:** TypeScript · React 18 · Vite · LocalStorage

## Запуск

```bash
npm install
npm run dev      # режим розробки
npm run build    # перевірка типів + production-збірка
npm run preview  # перегляд збірки
```

## Функціонал

- Перегляд списку творів (назва, художник, тип, ціна, доступність)
- Сортування за ціною (зростання / спадання), фільтри за художником і типом, пошук за назвою
- Додавання твору з валідацією:
  - назва — не порожня, до 99 символів
  - художник — не порожній
  - тип — вибір із наперед визначених
  - ціна — число, більше нуля
  - доступність — для продажу / лише експозиція
- Видалення твору
- Збереження стану в LocalStorage; при першому запуску показано 4 твори

## Структура

```
src/
  App.tsx                       композиція сторінки
  types.ts, data.ts             типи та початкові дані

```
